# NetCEC

[English](README.md) · **Русский**

**NetCEC управляет Sony Bravia и Android/Google TV по домашней сети**, HDMI-CEC не нужен. Sony работает через
собственный IP API, остальные Android/Google TV — по ADB, если доступна отладка по сети. При пробуждении ТВ
переключается на HDMI компьютера. Нажатие PS при уже работающем ПК возвращает ТВ с другого входа на выбранный
HDMI. При уходе в сон или выключении ТВ переходит на домашний экран или выключается. Это плагин [Decky Loader](https://decky.xyz/) для игрового режима.

## Что умеет

- **При пробуждении:** включает ТВ и переключает его на ваш HDMI-вход при запуске или пробуждении.
- **Нажатие PS возвращает к ПК:** пока компьютер работает, переключает ТВ с другого входа на выбранный HDMI.
  Если DualSense Edge отключился для экономии энергии, нажатие PS переподключает его и затем возвращает ТВ к ПК.
- **При уходе в сон** и **при выключении:** вы выбираете одно из двух действий: отправить ТВ на домашний экран
  Android TV (чтобы он не показывал «Нет сигнала») или выключить его. При перезагрузке ТВ не трогается.
- **Не мешает, если на ТВ смотрят что-то другое:** оба действия выполняются, только если ТВ в этот момент на вашем
  HDMI-порту.
- **Выбор USB-устройств, которые могут будить приставку,** например Bluetooth-адаптер можно, мышь нельзя.
- **Интерфейс на русском и английском** (по языку Steam или по вашему выбору).

- **Может показывать, что сделал:** включите «Журнал действий», и в панели появится список последних действий
  (время, что произошло, за сколько переключился вход). По умолчанию он выключен, и пока выключен, ничего не
  записывается.
- **Находит ТВ, если у него сменился адрес** (роутер выдал новый): по MAC-адресу. Всё равно лучше закрепить за
  ТВ постоянный адрес в роутере.
- **Без всплывающих уведомлений:** результат виден на ТВ и в списке.

## Что понадобится

- Устройство на SteamOS с установленным Decky Loader.
- Телевизор в одной сети с приставкой, один из:
  - **Sony Bravia** (Android TV): управляется через IP-управление Sony с PIN. Проверено.
  - **Модели Android TV / Google TV с ADB:** управляются по отладке сети. Для TCL есть готовая карта HDMI-входов;
    для других ТВ входы можно обучить, если телевизор сообщает активный HDMI через ADB.

## Установка и обновление

Одна и та же команда ставит плагин и позже обновляет его (всегда берётся последний релиз с GitHub).
Настройки и сопряжение с ТВ сохраняются.

**Прямо на SteamOS-приставке.** Переключитесь в режим рабочего стола, откройте терминал (Konsole) и выполните:

    curl -fsSL https://raw.githubusercontent.com/MSPortnov/NetCEC/main/install.sh | bash

В первый раз понадобится пароль пользователя `deck` (если не задавали, задайте командой `passwd`): его спросит `sudo`.

**С другого компьютера (macOS или Linux).** Один раз на приставке включите SSH и посмотрите её IP-адрес:

    sudo systemctl enable --now sshd
    ip -4 addr | grep inet

Затем на своём компьютере (вместо `192.168.1.101` подставьте свой IP):

    ssh -t deck@192.168.1.101 'curl -fsSL https://raw.githubusercontent.com/MSPortnov/NetCEC/main/install.sh | bash'

**Без терминала.** В Decky откройте Настройки > General и включите *Developer mode*. Затем откройте раздел
*Developer*, выберите *Install Plugin from URL* и вставьте:

    https://github.com/MSPortnov/NetCEC/releases/latest/download/NetCEC.zip

Установка и обновление перезапускают Decky, а NetCEC при запуске включает ТВ, поэтому телевизор может включиться.
Скрипт короткий, [прочитайте его](install.sh) перед запуском.

## Настройка

1. **На телевизоре.**
   - *Sony Bravia:* откройте Настройки > Сеть > Настройка домашней сети > IP-управление. Установите
     *Аутентификация* в **Normal** и включите **Remote start**.
   - *Android TV (TCL и другие):* включите «Для разработчиков», затем **Отладку по сети** (отладка по USB).
2. **В NetCEC:** при включённом телевизоре нажмите **Найти ТВ в сети** (при первом открытии плагин ищет сам)
   и выберите свой телевизор в списке. Единственный найденный ТВ выбирается автоматически. Если поиск
   ничего не нашёл, введите IP-адрес из сетевых настроек ТВ. После выбора телевизора кнопка поиска
   сменится на кнопку сопряжения. Чтобы снова запустить поиск, очистите поле IP-адреса.
3. - *Sony:* нажмите **Показать PIN на ТВ**. На экране телевизора появится код. Введите его в поле
     **PIN с экрана ТВ** и нажмите **Подтвердить PIN**.
   - *Android TV:* нажмите **Подключить**. ТВ спросит «Разрешить отладку по USB?»: выберите **Всегда разрешать**
     (плагин ждёт 25 секунд; если опоздали, нажмите «Подключить» ещё раз).
4. В строке состояния появится *Сопряжено*. (В списке найденных ТВ рядом с подключаемыми по ADB написано
   «Android TV»; для Sony ничего не меняется.)
5. Выберите **HDMI-порт**, к которому подключена приставка. Затем в трёх разделах *При пробуждении*,
   *При уходе в сон* и *При выключении* задайте, что делать телевизору. Под каждым выбором плагин одной фразой
   пишет, что он будет делать. Для ADB нажмите кнопку обучения выбранному порту.

Сопряжение продлевается само при каждом использовании. Если оно потеряно (например, вы удалили устройство в
настройках ТВ), строка состояния попросит выполнить сопряжение заново.

### Android TV: что нужно знать

- Sony автоматически работает через Sony IP API; найденные Android/Google TV — через ADB. Отладка по сети
  должна работать на порту 5555; новый режим Wireless debugging с отдельным портом сопряжения пока не поддержан.
- На сопряжённом Android/Google TV нажмите **Обучить определению HDMI 4**, если в настройках выбрали HDMI 4.
  ТВ откроет главный экран и сразу переключится на выбранный порт. Плагин сохранит ID входа, если два
  последовательных чтения совпадут. Некоторые модели не сообщают активный HDMI-вход через ADB.
- При пробуждении плагин переключает выбранный HDMI. После обучения он также проверяет, что ТВ действительно
  показывает нужный вход; без подтверждения сообщает, что команда отправлена, но не подтверждена.

## Проверка без телевизора

Нет под рукой Sony Bravia? Убедиться, что плагин загружается и работает, всё равно можно:

- Откройте NetCEC в меню быстрого доступа. Без IP-адреса статус показывает *Не настроено*, с введённым
  адресом показывает *Не сопряжено*.
- Нажмите **Найти ТВ в сети**: если в вашей сети нет Sony Bravia, статус покажет *Ничего не найдено*.
- Введите любой IP-адрес и нажмите **Показать PIN на ТВ**: телевизора нет, поэтому статус сообщит
  *Нет связи* (запрос завершился с ошибкой, больше ничего не происходит).
- В списке **Источники пробуждения** видны ваши USB-устройства. Переключатель действительно меняет
  настройку пробуждения устройства, и она восстанавливается после перезапуска.
- Если включён «Журнал действий», список под ним показывает каждое пробуждение, сон и выключение со временем и
  результатом.
- В разделе «При уходе в сон» строка «Перехват сна (systemd)» должна показать *активен*, а после сопряжения
  ТВ ещё и *блокировка удерживается*.
- Смените **Язык** и убедитесь, что интерфейс и сообщения меняются.
- Журнал в `~/homebrew/logs/NetCEC/` показывает, что плагин делал при запуске, сне и пробуждении.

## Если что-то не работает

- **ТВ не находится.** Сначала включите ТВ. ТВ и приставка должны быть в одной сети (не в разных сегментах
  Wi-Fi или VLAN); иначе введите IP-адрес вручную. В журнале `~/homebrew/logs/NetCEC/` перечислены все
  устройства, которые ответили на поиск.
- **Телевизор не включается.** Проверьте, что на ТВ включён *Remote start* и что в режиме ожидания телевизор
  не отключает сеть (в настройках ТВ ищите «сетевой режим ожидания» или похожий пункт).
- **В статусе «Сопряжение потеряно или истекло».** Нажмите *Разорвать пару с ТВ* и повторите сопряжение
  (шаги 2–4).
- **ТВ не реагирует после перезапуска роутера.** Если ТВ несколько секунд не отвечает, плагин ищет его заново по
  MAC-адресу и пишет об этом в журнале действий (если он включён). Если не вышло, закрепите за ТВ постоянный адрес в роутере
  и введите его в плагине.
- **Настройки затемнены.** Пробуждение, сон и выключение работают только для сопряжённого ТВ: сначала выполните
  сопряжение (шаги 2–4).
- **При сне и выключении ничего не происходит.** Действия выполняются только для сопряжённого ТВ (в статусе
  *Сопряжено*), а строка «Перехват сна (systemd)» в плагине должна показывать *активен*.
- **ТВ остаётся включённым, когда приставка спит или выключается.** ТВ трогают, только если он показывает ваш
  HDMI-порт; на другом входе, на главном экране или если он не успел ответить, его не трогают. Строка лога
  `leave: input check ...` показывает, что ответил ТВ. Проверьте, что HDMI-порт в плагине тот, к которому
  подключена приставка.
- **Логи:** `~/homebrew/logs/NetCEC/`.

## Для разработчиков

- Бэкенд: `main.py` (Python, работает от root: пишет USB-настройки пробуждения и берёт блокировку systemd).
  Фронтенд: `src/index.tsx` (React, собирается командой `pnpm build` в `dist/`).
- Поиск ТВ: SSDP (UPnP), мультикаст-запрос; устройство попадает в список, только если в его описании
  производитель Sony и Scalar Web API, а описание загружается только с того устройства, которое ответило.
- Управление ТВ: Sony Bravia IP Control (REST и IRCC), сопряжение по PIN, Wake-on-LAN как запасной способ включения.
- При запуске и пробуждении ничего не спрашивается и ничего не ждётся: кнопка «Назад» пульта (она прерывает
  заставку) и переключение входа уходят в один и тот же момент (у Sony два запроса одновременно; у Android TV одна
  строка shell с «Назад» в фоне, а состояние питания спрашивается сначала, потому что спящий ТВ молча проглотил бы
  команду). Затем плагин спрашивает ТВ каждые 0,4 с, пока тот не назовёт порт: после пробуждения
  ТВ нужны несколько секунд, а повторная команда только перезапускает его переключение. Команда отправляется
  ещё раз, только если за 8 с подтверждения нет; после этого результат «команда отправлена, не подтверждена».
  ТВ, который не отвечает, будят (включение + Wake-on-LAN) каждые ~3 с, максимум 45 с. Каждое переключение пишет
  в журнал одну строку со временем каждого шага и ответами ТВ.
- Сон и выключение: бэкенд следит за systemd-logind (`PrepareForSleep` / `PrepareForShutdown` через
  `dbus-monitor`) и держит короткую задерживающую блокировку (`systemd-inhibit`, несколько секунд), чтобы успеть
  выключить ТВ до отключения сети. Запасные источники: события интерфейса Steam и детектор скачка часов.
  Новый сон или выключение отменяет ожидающие команды пробуждения. Действие при выключении выполняется,
  когда systemd подтверждает выключение или остановку ПК.
  Каждое настоящее пробуждение обрабатывается ровно один раз: ядро считает завершённые попытки сна
  (`/sys/power/suspend_stats/success` + `fail`), а источник, который сообщает тот же счётчик, считается
  дубликатом (если счётчика нет, запасной вариант таймер 20 с; в логе написано, какой способ используется).
- Журнал действий лежит в `events.json` рядом с настройками (20 записей, в панели 5). По умолчанию он выключен;
  пока выключен, ничего не пишется, а при выключении файл удаляется. (Технический лог в папке Decky пишется
  всегда: по нему снимается диагностика.) Если ТВ 6 с не
  отвечает и MAC-адрес известен, один сетевой поиск ищет Sony-ТВ с этим MAC и обновляет сохранённый адрес.
- Настройки хранятся в папке настроек плагина Decky (`settings.json`, читать может только владелец). Файл пишется
  атомарно, последняя рабочая версия сохраняется как `settings.json.bak`; повреждённый файл переименовывается в
  `settings.json.corrupt`, а берётся резервная копия, поэтому сопряжение не теряется. Ключ сопряжения из
  бэкенда не выходит, а все значения из интерфейса проверяются.
- Тесты (телевизор и сеть не нужны): `python3 -m unittest discover -s tests`. В CI они запускаются при каждой отправке.
- Сборка из исходников и установка с другого компьютера (macOS или Linux; Node.js скачивается сам,
  если его нет, а pnpm подтягивается на лету):

      git clone https://github.com/MSPortnov/NetCEC.git
      bash NetCEC/deploy.sh 192.168.1.101

  Обновление: `cd NetCEC && git pull && bash deploy.sh`. Пользователь SSH `deck`, другого можно задать так:
  `DECK_USER=имя`; `bash deploy.sh <IP> logs` сохраняет диагностические логи в `~/Downloads`.
- Decky запускает плагины в урезанном Python (часть стандартной библиотеки, например `xml.etree`, отсутствует).
  `python3 tools/check_imports.py` завершится ошибкой, если `main.py` импортирует модуль, которого нет в списке
  проверенных на устройстве; эту проверку запускает и сборка релиза. Новый импорт сначала проверьте на
  реальном устройстве, затем добавьте в список.
- Android TV: `py_modules/netcec_adb.py` это небольшой собственный ADB-клиент (ключ RSA создаётся при первом
  использовании и хранится в папке настроек, права 0600; публичный ключ предлагается ТВ, и пользователь один раз
  его подтверждает). Сторонние библиотеки не нужны (в Python Decky их всё равно не поставить). Если клиент не
  загрузился, пропадает только поддержка Android TV; Sony не затрагивается. Драйвер выбирается настройкой `driver`
  (`sony` или `adb`).
- Релиз: поднимите `version` в `package.json`, закоммитьте, затем `git tag v1.2.3 && git push origin v1.2.3`.
  GitHub Actions соберёт плагин и приложит `NetCEC.zip` (имя всегда такое, плюс файл `.sha256`) к новому
  релизу; сборка завершится ошибкой, если тег не совпадает с `package.json`.
